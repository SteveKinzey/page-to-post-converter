# Page to Post Converter

Converts WordPress Pages into Posts, with or without Elementor.

## Features
- Convert individual or multiple pages into posts
- Preserve featured images
- Supports:
  - Filters: Author, Status, Keyword Search
  - Sort by Publish Date
  - Optional Elementor content preservation

## Version 1.3.2
- Elementor is no longer required
- "Preserve Elementor Data" only appears if Elementor is installed
