# Page to Post Converter

Converts WordPress Pages into Posts, with Elementor compatibility.

## Features
- ✅ Converts Pages into Posts while preserving content and featured image
- ✅ Elementor builder compatibility
- ✅ Bulk and single conversion buttons
- ✅ Filters: Author, Post Status, Title Search, Date Sorting (Newest/Oldest)

## Version 1.3.1
- Sort by publish date (Newest First / Oldest First)
- Works with all other filters and Elementor support toggle
