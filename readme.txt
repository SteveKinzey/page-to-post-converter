Convert WordPress pages into posts, preserving Elementor content and featured images.

== Description ==
A simple utility to convert WordPress Pages to Posts. Optionally preserves Elementor builder data and featured images.

== Installation ==
1. Upload the plugin zip file via WordPress Admin > Plugins > Add New > Upload.
2. Activate the plugin.
3. Go to Tools > Page to Post Converter.

== Frequently Asked Questions ==
= Does this support Elementor? =
Yes. Check the box to preserve Elementor data.
